# L1-C4 critique — §8 scaffold, §9 researcher.md, §10 synthesizer.md, §11 evidence contract

1. **Researcher prompt references a spec the subagent cannot see**
   - Anchor: §9 (OUTPUT block), §11
   - Class: broken-cross-ref
   - Defect: researcher.md is written verbatim as the subagent's entire system prompt, yet its OUTPUT section says "Write evidence/<qid>.json matching the contract in the spec's §11". The subagent never reads SPEC.md, and the brief it receives is defined as only {qid, brief, seed venues/queries, agent_id} — the schema is not in it.
   - Consequence: each researcher improvises the JSON shape; synthesizers and any downstream tooling keyed to §11 field names (quote_verified, snapshot_fidelity, matrix_rows) break or silently miss fields.
   - Severity: high
   - Fix sketch: inline the §11 JSON skeleton directly in researcher.md, or mandate the orchestrator paste it into every brief.

2. **snap.sh dies silently on curl failure, violating the spec's own no-silent-abandonment rule**
   - Anchor: §8 (snap.sh), §9 rule 6
   - Class: missing-failure-mode
   - Defect: `set -euo pipefail` plus `code=$(curl ...)` means any non-HTTP curl failure (DNS error, timeout exit 28, TLS error) aborts the script before meta.json or the snapshot telemetry event is written, possibly leaving a truncated .html behind. Rule 6 calls silent abandonment "the one unrecoverable mistake", but the reference tool commits exactly that on its most common failure path.
   - Consequence: blocked/flaky hosts (the G2/Crunchbase cases §9 rule 4 anticipates) produce no event, no meta.json, and stale partial files that grep may later match against.
   - Severity: high
   - Fix sketch: wrap curl with `|| code=000`, delete partials on failure, and always emit the event (or a dead_end) before exiting nonzero.

3. **Model-mediated fallback never produces the .txt the synthesizer verifies against**
   - Anchor: §9 rule 4, §10 step 2, §11
   - Class: contradiction
   - Defect: the last-resort path says to snapshot the WebFetch digest "via Write with fidelity model-mediated in meta.json" but specifies no filenames — snap.sh's .html/.txt pair only exists on the curl path. §10 step 2 verifies every claim against "its snapshot .txt", and §11's `snapshot` field points to a `.html`. For model-mediated claims there is no defined .txt (nor a defined .html), so the entailment step and rule 3's grep check have no target.
   - Consequence: synthesizers either fail to find files (marking valid low-confidence claims [UNVERIFIED] for the wrong reason) or invent their own file conventions per agent.
   - Severity: medium
   - Fix sketch: specify the Write fallback must emit `<slug>.txt` + `<slug>.meta.json` under snapshots/<qid>/ with the digest as the .txt body.

4. **Wayback rung of the fallback ladder is unusable from inside researcher.md**
   - Anchor: §9 rule 4
   - Class: unstated-assumption
   - Defect: rung (b) says fetch `https://web.archive.org/web/<timestamp>/<url>` but the verbatim prompt never says how to obtain `<timestamp>` (CDX lookup lives in §7/§15 per the map, which the subagent doesn't see). check-globally: confirm whether §7/§15 text is ever surfaced to researchers via the brief.
   - Consequence: researchers guess timestamps or fetch the bare `web.archive.org/web/<url>` redirect form, which WebFetch returns unfollowed per the prompt's own redirect warning — rung (b) dead-ends and hard-blocked venues collapse straight to `unknown`.
   - Severity: medium
   - Fix sketch: add one line to researcher.md: query the CDX API (`web.archive.org/cdx/search/cdx?url=...&limit=1`) or use the `/web/2/<url>` latest-capture form.

5. **Split-file glob `evidence/<qid>*.json` collides with child qids and leaves synthesis ownership ambiguous**
   - Anchor: §10 step 1, §11 (split_proposal)
   - Class: ambiguity
   - Defect: splits mint child qids like Q4a1 whose files (`evidence/Q4a1.json`) match the parent's glob `evidence/Q4a*.json`. The chunk never says whether children get their own synthesizer (in which case the parent's glob double-reads them) or the parent synthesizer covers all (in which case sections/<child-qid>.md never exists).
   - Consequence: claims verified and footnoted twice under two sections, or child evidence orphaned — either way findings.md's per-question accounting is wrong.
   - Severity: medium
   - Fix sketch: name split files `evidence/<parent>.part-<n>.json`, or state explicitly that child qids are synthesized only by the parent-qid synthesizer.

6. **printf-built JSON does no escaping**
   - Anchor: §8 (snap.sh)
   - Class: missing-failure-mode
   - Defect: URL is interpolated into meta.json and the telemetry event with `printf %s` and an unquoted heredoc; any `"` or `\` in the URL (common in query strings) yields invalid JSON lines.
   - Consequence: dashboard (§13) and post-hoc audits fail to parse the JSONL, or drop the affected rows silently.
   - Severity: low
   - Fix sketch: build both JSON blobs with `python3 -c 'import json,sys; ...'` like the extractor step already does.

7. **Synthesizer's buffered one-shot telemetry loses everything on crash**
   - Anchor: §10 step 4
   - Class: missing-failure-mode
   - Defect: events are accumulated in-context and written once at the end; a synthesizer that hits its own 32k cap, context limit, or errors mid-run leaves zero telemetry, and nothing tells the orchestrator to treat a missing synth-<qid>.jsonl as a failure signal.
   - Consequence: dashboard undercounts synth reads with no visible gap; a dead synthesizer is indistinguishable from one not yet dispatched.
   - Severity: low
   - Fix sketch: orchestrator treats absent telemetry/synth-<qid>.jsonl after a synth `done` reply (or timeout) as a protocol violation to re-run.
